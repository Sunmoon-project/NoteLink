# 1:1 채팅의 스터디룸 초대

작성일: 2026-11-14

스터디룸 친구 초대는 친구와의 1:1 채팅에 초대 카드를 보내고, 받은 사람이 카드에서 참여해 방에 들어가는 흐름이다.

## 흐름

1. 방 참여자가 친구 초대 화면에서 친구를 선택한다.
2. 모바일 앱이 `POST /api/v1/study-rooms/:id/invites`에 친구 ID를 보낸다.
3. NestJS는 요청자의 로그인 상태와 방 참여 여부, 친구 관계, 대상 계정, 방 정원을 확인한다. 초대 가능한 친구는 스터디룸 `members`에 `invited` 상태로 기록한다.
4. 서버는 정렬된 두 사용자 ID로 1:1 채팅방을 찾거나 만든다. `directKey` 유일 인덱스로 같은 두 사용자 사이에 방이 중복 생성되지 않게 한다.
5. 서버는 `messages` 컬렉션에 `study_room_invite` 메시지를 저장하고, 상대가 채팅에 연결돼 있으면 Socket.IO `chat:message` 이벤트로 전달한다.
6. 친구는 홈 화면의 대화 목록에서 1:1 채팅을 열어 저장된 초대 카드를 확인한다. 오프라인이었으면 채팅 기록을 조회해 카드를 받는다.
7. `스터디룸 참여하기`를 누르면 앱이 참여 코드를 제출한다. 서버는 멤버 상태를 `invited`에서 `joined`로 바꾸고, 성공하면 앱이 해당 스터디룸 화면으로 이동한다.

## 구성 요소

- **모바일 채팅 화면** (`apps/mobile/src/features/social/screens.tsx`): 대화 기록과 초대 카드를 표시하고, 카드의 참여 코드를 제출한다. 채팅방에 Socket.IO로 입장해 실시간 메시지를 받고, 입장 시 누락된 메시지도 동기화한다.
- **모바일 스터디룸 초대 화면** (`apps/mobile/src/features/studyroom/tools.tsx`): 친구 선택과 초대 요청을 담당한다.
- **스터디룸 API** (`apps/api/src/modules/studyroom/study-rooms.controller.ts`, `study-rooms.service.ts`): 초대 권한·친구 관계·방 정원을 확인하고 멤버를 초대 상태로 저장한다.
- **1:1 채팅 API와 서비스** (`study-chat.controller.ts`, `study-chat.service.ts`): 친구 채팅방을 조회하거나 생성하고, 초대 메시지와 대화 기록을 MongoDB에 저장한다.
- **Socket.IO 게이트웨이** (`study-chat.gateway.ts`): 채팅방 참여 권한을 확인하고 실시간 초대 메시지와 일반 메시지를 전달한다.
- **MongoDB** (`chat_rooms`, `messages`, `study_rooms`): 1:1 채팅방, 초대 카드, 스터디룸 멤버 초대 상태를 보관한다.

## 일반 1:1 채팅 권한

`POST /api/v1/chat-rooms/direct`는 친구 관계가 확인된 사용자 사이의 채팅방 ID를 반환한다. 기록 조회와 Socket.IO 입장·전송에서는 채팅방 유형에 맞는 권한을 다시 확인한다. 스터디룸 채팅은 현재 방 참여 상태를, 1:1 채팅은 채팅방 멤버와 현재 친구 관계를 확인한다.

`requireChat()`의 조회 조건이 스터디룸 채팅만 허용하면 1:1 채팅도 기록 조회와 Socket.IO 입장에서 거부된다. 두 채팅 유형을 모두 조회한 뒤 각 유형에 맞는 권한 검사를 수행해야 한다.

## 제한과 확인 사항

- 친구가 아닌 사용자나 방에 참여하지 않은 사용자는 초대할 수 없다.
- 초대 메시지는 대화 기록에 저장되므로 수신자가 나중에 채팅을 열어도 확인할 수 있다.
- 같은 초대 요청의 메시지 저장에는 고정 `clientId`를 사용해 중복을 줄인다.
- 방 정원이 찬 경우 초대를 거부한다. 이미 참여 중이거나 초대된 사용자는 다시 추가하지 않는다.
- 초대 카드는 참여 코드를 사용한다. 코드가 유효하지 않거나 방에 들어갈 수 없는 상태면 서버 응답을 앱에서 안내한다.
- 이번 변경의 테스트 파일은 `apps/api/test/study-chat-direct.test.ts`, `apps/api/test/study-room-join.test.ts`, `apps/mobile/src/__tests__/social.test.tsx` 등이다. 실제 기기에서 두 계정으로 초대 카드 실시간 수신과 방 입장을 확인한다.
