# 스터디룸 라이브 연결

- 모바일은 `POST /api/v1/study-rooms/:id/livekit-token`으로 토큰을 받은 뒤 LiveKit에 연결한다.
- 참가자의 카메라·마이크 표시는 LiveKit 참가자와 트랙 상태를 기준으로 갱신한다. 연결이 끊기거나 재연결 중이면 이전 미디어 상태를 표시하지 않는다.
- 서버는 로그인과 현재 방 참여 여부를 확인하고, 방 ID와 사용자 ID로 제한된 5분 토큰을 발급한다. 토큰은 연결 수명이 아니며 연결 중에는 LiveKit이 갱신한다.
- API 서버 환경에 `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`을 설정한다. 키와 시크릿은 앱 번들에 넣지 않는다.
- 자진 퇴장이나 방장 강퇴 시 Socket.IO 구독을 해제하고 LiveKit 참여자를 제거한다. LiveKit 연결 해제가 실패하면 실패를 알리며 같은 요청을 다시 보낼 수 있다. 방 참여 상태는 이미 변경됐을 수 있다.
- 방장이 자진 퇴장하면 남은 참여자 중 가장 먼저 입장한 사람에게 방장을 넘긴다. 입장 시각이 같으면 사용자 ID 순으로 정한다. 방장 변경, 기존 방장 퇴장, 참여자 수 갱신은 한 번의 MongoDB 문서 갱신으로 처리한다.
- 방장이 혼자 남은 경우의 퇴장 정책은 미정이며 현재는 기존처럼 퇴장이 거절된다. 화면의 뒤로가기 동작은 방 멤버십 퇴장 API와 별개이므로 프론트엔드에서 해당 API를 연결해야 방장 위임이 발생한다.
- LiveKit Cloud에서 참여자 제거 시 기존 토큰을 폐기한다. 자체 서버는 기존 토큰 폐기 동작이 다르므로 별도의 재접속 차단 설계가 필요하다.
- 토큰 발급 및 참여자 제거를 단위 테스트했으며 실제 서버의 인증과 토큰 발급은 확인했다. 실제 두 기기의 캠·음성 및 네트워크 장애, 강퇴 시 동시성은 추가 검증이 필요하다.
